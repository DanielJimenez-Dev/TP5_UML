# Ejercicios de implementacion de relaciones en Java y UML:
- Este repositorio contiene una serie de ejercicios diseñados para demostrar la implementación práctica de los principales 
  tipos de relaciones orientadas a objetos en Java, tal como se definen en el Diagrama UML de Clases.

# Conceptos centrales aplicados:
- Trabajamos con tres tipos fundamentales de relaciones para modelar cómo las clases interactúan y dependen unas de otras:
  - Asociación (Asociación Simple / Unidireccional)
  - Asociación Bidireccional.
  - Agregación (Relación "Todo-Parte" Débil)

# Metodologia de desarrollo
 1. Analisis de relaciones.
 2. Modelado UML.
 3. Implementacion de clases
 4. Cierre de ciclos.
 5. Verificacion.
